# Extraction roadmap

## Phase 0 — provenance-preserving foundation

- Track `bilawalsidhu/gods-eye-view` as upstream.
- Retain the MIT license and upstream attribution.
- Establish FoundUps Earth identity and constitutional boundaries.
- Inventory third-party datasets and disable noncommercial defaults for distributable builds.

## Phase 1 — spatial kernel

- Extract renderer, camera, annotation, temporal-state, share-state, and layer interfaces.
- Break up the Vite proxy and large UI/data modules.
- Add provider-neutral adapters for maps, models, voice, and storage.
- Define conformance tests for layer provenance and failure honesty.

## Phase 2 — GeoSync POC

- Implement `GeoEvent` validation and local event storage.
- Add AutoPost import using video, location, orientation, transcript, and hashes.
- Render unverified, corroborated, verified, disputed, and resolved states distinctly.
- Demonstrate duplicate grouping and before/after observation chains.

## Phase 3 — first action loop

- Connect GotJunk as the first domain consumer.
- Convert a verified dumping cluster into bounded work.
- Attach worker authorization, work receipts, and outcome evidence.
- Verify the changed condition through a subsequent AutoPost capture.

## Phase 4 — place hubs

- Represent FoundUps Houses and village hubs.
- Publish consented resources, events, equipment, projects, and local needs.
- Support local/private views distinct from public views.

## Phase 5 — AR and play

- Define an experience manifest independent of a specific UI gesture.
- Add nearby mission discovery and spatial anchors.
- Prototype “RedDog, I want to play” as a mode negotiation flow.
- Keep game mechanics optional and prevent reward systems from incentivizing unsafe capture or fabricated observations.

## Release gates

No production release until authentication, authorization, privacy projection, evidence retention, provider licensing, cost governance, audit receipts, accessibility, mobile performance, offline synchronization, and abuse testing have explicit passing evidence.
